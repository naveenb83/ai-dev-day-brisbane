# Lab 2 — AI on your data <span class="lvl lvl-200">L200</span>

**~25 minutes**

## Goal

Apply AI to a **whole table** with plain SQL — classify and summarise text at
scale using **AI Functions**. No app, no ML background required.

## You'll learn

- AI as a *column*, not a chat window.
- Which built-in function to reach for, and how to spot-check the results.

## Steps

1. **Make a tiny dataset** in your schema (swap in the catalog/schema from Lab 0):
   ```sql
   CREATE OR REPLACE TABLE {your_catalog}.{your_schema}.reviews AS
   SELECT * FROM VALUES
     (1, 'The battery lasts all day and setup was easy. Love it.'),
     (2, 'Stopped working after a week and support never replied.'),
     (3, 'Does the job but the app is confusing to navigate.'),
     (4, 'Best purchase this year — saved me money already!')
   AS t(id, review_text);
   ```
2. **Classify sentiment and topic:**
   ```sql
   SELECT
     id,
     review_text,
     ai_analyze_sentiment(review_text)                                   AS sentiment,
     ai_classify(review_text, ARRAY('battery','support','app','price'))  AS topic
   FROM {your_catalog}.{your_schema}.reviews;
   ```
3. **Summarise:**
   ```sql
   SELECT id, ai_summarize(review_text, 12) AS short_summary
   FROM {your_catalog}.{your_schema}.reviews;
   ```
4. **Free-form with `ai_query`.** Draft a one-line reply to each review:
   ```sql
   SELECT
     id,
     ai_query(
       'databricks-meta-llama-3-3-70b-instruct',  -- use an endpoint available in your workspace
       'Write a warm one-sentence reply to this customer review: ' || review_text
     ) AS suggested_reply
   FROM {your_catalog}.{your_schema}.reviews;
   ```
   *(If that endpoint name isn't available, pick one your facilitator names, or
   use `ai_gen` for a quick test.)*
5. **Spot-check.** Read a few rows. Do the labels look right? Note any the model
   got wrong — that's why we [evaluate](../working-with-ai/why-we-evaluate.md).

## Expected result

- A table where each review has a sentiment, a topic, a summary and a suggested
  reply — generated by AI, in SQL.

## Stretch

- Add `ai_mask(review_text, ARRAY('person','phone'))` to see PII redaction.
- Try `ai_extract` to pull structured fields from a longer text column.
- Imagine this over 1,000,000 rows — discuss cost (see
  [cost & performance](../production-governance/cost-and-performance.md)).
