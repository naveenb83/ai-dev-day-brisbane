# AI Dev Day Brisbane

Welcome. This is a **learn-at-your-own-level guide to AI** — built for a room
full of people from different companies, with very different starting points.
Whether today is the first time you've thought hard about how AI works, or you
build agents for a living, there's a lane here for you.

Everything follows one simple pattern:

> **Plain English first → then "how Databricks does it".**
>
> We explain each idea in a vendor-neutral way anyone can follow, *then* show how
> it looks on the Databricks platform you'll use in the hands-on labs.

## Find your level

We tag everything **L100 → L400**. You don't have to start at L100 — pick where
you're comfortable and move up.

<div class="grid cards" markdown>

-   <span class="lvl lvl-100">L100</span> **Foundations**

    ---

    What AI, machine learning and generative AI actually are. No maths, no
    jargon. If AI still feels like magic, start here.

-   <span class="lvl lvl-200">L200</span> **Working with AI**

    ---

    Prompting, retrieval (RAG), vector search, structured outputs, and why we
    *evaluate* AI. The "I can use this at work" level.

-   <span class="lvl lvl-300">L300</span> **Building with AI**

    ---

    Agents, tools, memory, and multi-agent systems — and the frameworks that run
    them. For people who'll build things.

-   <span class="lvl lvl-400">L400</span> **Production & governance**

    ---

    Evaluation at scale, observability, guardrails, security, and cost. What it
    takes to run AI for real, safely.

</div>
