# AI Dev Day Brisbane

An **L100 → L400 AI literacy encyclopedia**, glossary, prompt library and hands-on
Databricks labs — built for mixed-audience client dev days.

> 🚧 This repository is being assembled section by section. The full site
> structure, contribution guide and local-preview instructions land in the first
> scaffold PR.

## What this will be

- **Encyclopedia** — core AI/GenAI concepts explained plainly first, then *"how
  Databricks does it"*, grouped by learning level (L100 foundations → L400
  production & governance).
- **Glossary** — plain-English definitions, each with a Databricks note.
- **Prompt library** — how to write good prompts, reusable templates, worked
  examples, and meta-prompting (using AI to write your prompts).
- **Hands-on labs** — guided exercises attendees run in their own Databricks
  workspace.
- **Facilitator guide** — run-of-day and prep checklists for whoever runs the day.

Rendered as a [MkDocs Material](https://squidfunk.github.io/mkdocs-material/) site.
